The first release candidate of Ahab: a self-hosted workspace for Claude Code, Codex, Pi and ACP agents, with files, terminals and Git beside them.

## Install

On Linux (x86_64, arm64) or macOS (Apple silicon):

```sh
curl -fsSL https://github.com/spelvia/ahab/releases/latest/download/install.sh | sh
ahab up
```

The installer puts `ahab` in `~/.local/bin`, adds it to your PATH and checks the archive's SHA-256. `ahab up` starts Ahab in the background (and at login) and opens the web app. See the README for the details.

## What is in it

- **Projects:** a folder on a machine, with sessions, files, terminals, search and Git.
- **Agent sessions:** Claude Code, Codex, Pi and ACP agents, with their questions, plan approvals and forms answered in the chat, skills and MCP prompts from `/`, files added with `@`, queued messages you can reorder and edit, background tasks and subagents.
- **Machines:** run agents on other computers that join the server (`ahab machines add you@host`).
- **Plugins** that add views, commands and settings.
- The web app works on phones too, and pairs each browser with the server.

## Known limits

- Release candidate: data formats may still change before 0.1.0.
- Builds for Linux x86_64 and arm64 (glibc 2.36 or newer) and macOS on Apple silicon only.
- While the repository is private, downloads need a GitHub login: use `gh release download` (see the README).
